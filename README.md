# Jainika 🌸 — AI & ML Engineer Portfolio (Pink & Floral Butterfly Edition)

A high-performance, creative portfolio website designed and built for **Jainika**, a Computer Science and Engineering (CSE) student specializing in **Artificial Intelligence & Machine Learning (AI & ML)**.

Featuring a soft, dreamy **pink aesthetic** infused with **3D animated fluttering butterflies**, **drifting sakura flower petals**, and **rose-tinted glassmorphism**.

---

## 🌸 Creative Aesthetic & Features

1. **Dreamy Pink & Floral Theme**:
   - Soft petal-pink gradients (`#fff0f5`, `#fdf2f8`, `#fce7f3`) paired with rich berry plum typography (`#4a1529`) for contrast and legibility.
   - Ambient glowing rose and lavender orbs.
   - Built-in theme switcher supporting a **Pink Blossom** default and an optional **Midnight Rose** dark mode.

2. **3D Animated Butterflies & Falling Sakura Petals**:
   - 4 ambient 3D SVG butterflies with fluttering wings drifting across the viewport.
   - Interactive HTML5 Canvas in the Hero section with falling cherry blossom petals that sway and react to mouse movement.
   - Interactive click effect: clicks spawn a burst of floating sparkles ✨, flowers 🌸, hearts 💖, and butterflies 🦋.

3. **Pink Cyber-Blossom Terminal**:
   - A glassmorphism interactive code terminal in the hero section displaying live model checkpoint loading (ResNet-50 + DistilBERT), validation loss (0.0241), and low-latency inference (14ms).
   - Floating badges for Deep Learning and Computer Vision.

4. **Live AI Sentiment & Emotion Garden**:
   - Client-side Natural Language Processing (NLP) inference simulator.
   - Calculates sentiment polarity, confidence percentages, token weights, and emotion distribution bars in real time.
   - Interactive prompt chips for quick tests.

5. **Technical Skills Matrix**:
   - Categorized tabs (*All Skills, AI & Machine Learning, Languages & Core CS, Web & APIs, Tools & Platforms*).
   - Animated proficiency level bars with tags (PyTorch, TensorFlow, OpenCV, Hugging Face, C++, Python, SQL, etc.).

6. **Featured AI Projects with Interactive Case Studies**:
   - **NeuroVision AI**: Automated Medical MRI & CT Scan Diagnostic AI (ResNet-50 + Grad-CAM, 98.4% Accuracy).
   - **OmniSense NLP**: Multilingual Sentiment & Emotion Classifier (Fine-Tuned DistilBERT, 0.93 F1-score).
   - **AeroTrack Vision**: Autonomous Real-Time Multi-Object Detection & Trajectory Tracking (YOLOv8 + ByteTrack at 62 FPS).
   - **StockPulse Predictor**: Financial Time-Series Forecasting & Sentiment Engine (LSTM + FinBERT).
   - Dynamic popup modal with in-depth architectures, benchmarks, and dataset specs.

7. **Academic Milestones & Connect**:
   - B.Tech CSE (AI & ML) degree curriculum breakdown with core coursework.
   - Working contact form with real-time validation and animated confirmation.
   - One-click copy email button with feedback toast notification (`jainika.csemil@gmail.com`).
   - Resume preview and download modal.

## 🚀 How to View Locally

Simply open `index.html` in your browser:

- **Option 1**: Double-click `index.html` in Finder or drag it into Chrome, Safari, or Firefox.
- **Option 2 (Terminal)**:
  ```bash
  open index.html
  ```
- **Option 3 (Local Server)**:
  ```bash
  python3 -m http.server 8000
  # Then open http://localhost:8000 in your browser
  ```
